# Logo

`logo.svg` is a **placeholder mark**. When the final logo is ready:

1. Replace `assets/logo/logo.svg` with the final file (keep the same filename, or update the two
   `<img src="assets/logo/logo.svg">` tags in `index.html` — one in the header, one in the loader).
2. Use white (or light) artwork on a transparent background — the site is black.
3. Recommended: SVG, roughly landscape or square. The header renders it at 40px tall; the loader at 64px.
4. If the final logo is a full wordmark (already contains the name), delete the
   `<span class="header__logo-text">EZZELDEEN</span>` line in `index.html` so the name is not shown twice.
5. Optionally replace `assets/favicon.svg` with a 64×64 version of the mark.
